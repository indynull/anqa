[bold]Everywhere[/bold]
  Tab             Next control
  Shift+Tab       Previous control
  Arrows          Move in a list
  j / k           Move down / up in a list
  Enter           Open or activate
  Esc             Back or close
  ?               This panel
  Ctrl+P          Command palette for this screen
  F5              Refresh (also Ctrl+R)
  q               Quit when no field is focused

[bold]Sessions[/bold]
  /               Search (Tab completes the last token)
  s               Select (also Space)
  S               Select all
  E               Export a session bundle
  t               Tag the selected sessions
  Ctrl+O          Import a harness archive or anqa export
  x               Delete selected sessions (press twice)

[bold]Browser[/bold]
  [ ]  1-4        Timeline, Summary, Diff, Notes
  h / l / Left / Right    Previous / next turn on the Timeline
  j / k           Previous / next Timeline event, or previous / next note
  v               Filter (Subagents, Background, Workflows)
  Enter           Open a Timeline event or child; edit the focused note; next Diff match
  Shift+Enter     Previous Diff match
  Raw             Switch: this event as JSON
  N               New note
  y               Copy the selection or the focused / primary pane body
  Ctrl+Shift+C    Same as y
  E               Export a session bundle
  t               Tag this session
  x               Notes: focused note. Timeline / Summary / Diff: this session (press twice)

[bold]Pickers[/bold]
  s               Select
  Ctrl+S          Apply the selection
  Esc             Cancel

The footer lists primary keys. The palette lists the rest.

Desktop HUD shares ? / Esc / / / y / j k / h l (Timeline turns) / N
with this TUI. Tab moves between HUD controls. Ctrl+Tab or Ctrl+1-5
change panes; [ ] also scope Timeline turns (all / next).
HUD x deletes a note (press twice). Session delete and export (E) are
the terminal app.
A keys.toml remap applies on both surfaces. An overlay may set one
leader key, then one letter (leader+X). Esc or timeout cancels.
Copy examples/keys/colemak.toml to ~/.anqa/keys.toml for Colemak
home-row n/e list motion.
